# Student Final Grade Calculator

## Introduction

This project is a C++ application designed to calculate the final grades of students based on their homework results and exam results.

The program will allow users to enter student information, calculate final grades using the average or median of homework results, generate random grades, and read student data from a text file.

## Grade Calculation Formula

The final grade is calculated using the following formula:

**Final Points = 0.4 × Homework Result + 0.6 × Exam Result**

Where:
- **Homework Result:** The average or median of all homework grades.
- **Exam Result:** The student's exam grade.
- Homework contributes 40% to the final grade.
- The exam contributes 60% to the final grade.

## Project Goals

- Store student information using a `Person` class.
- Calculate final grades using the average or median.
- Generate random homework and exam results.
- Read student data from `Students.txt`.
- Sort students alphabetically and display formatted results.
